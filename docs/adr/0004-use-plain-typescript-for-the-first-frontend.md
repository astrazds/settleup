# Use plain TypeScript for the first frontend

SettleUp will start with a Hono-served HTML shell plus plain TypeScript, JavaScript, and CSS for the interactive frontend instead of Hono JSX, React, Vite, or another frontend framework. The first product surface is small enough that a framework would add build and deployment complexity before it earns its keep, and the choice can be revisited once the UI grows beyond simple forms, lists, polling, and state rendering.
